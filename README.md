This is my database for storing user information. 

I used users, like firstname, lastname and email as i didnt have any special inspiration so used what what in the assignment.

I named it "mynewdatabase" as you had in the assignment and it has a collection for users. 

Each user has basic info like their first and last name, plus their email address.

I made this database to practice CRUD operations with Node.js. 

It's pretty simple but it works! The database runs in a Docker container so I don't have to install MongoDB directly on my computer.

I can add new users, view all users, update their information, or delete them if needed. The email field is required and has to be unique so we don't get duplicate users.

This is my first time working with MongoDB and Mongoose, and I think it's a good starting point for learning about databases!
